# Redline County Retro

Redline County: Wide Open 2 (Road Not Found + Traffic) with the same game underneath and a late-90s
console's picture on top, made to run light on a phone or an ordinary laptop. It's the place to work on the
traffic, the police and the story without the full renderer in the way.

**The same:** the physics (Shiftlight 3's vehicle physics with Dirt Sleeper's off-road changes), the Digital
Engine synth, the streamed forty-mile county, every car and machine, the garage, the dyno lab, the career,
the races, the challenges, the county's people and their jobs, traffic on the highway and the streets, police
mode with the wanted levels and the helicopter, the recorded police voices. Those modules are the full game's
code as it was, cut into files.

**Different:** how it's drawn.

| | Full game | Retro |
| --- | --- | --- |
| Picture | HDR at screen resolution, TAA | 240 rows (180–480 in Settings), blown up with sharp pixels |
| Light | Cascaded sun shadows, headlight shadow map, reflection probe, SSR, volumetric fog, bloom | Sun or moon, sky ambient, the town's lamp grid (6–20 lamps a pixel by tier), headlights with their cut-off, a blob of shade under each car |
| Colour | ACES, 16-bit float to the screen | ACES, then 15-bit colour through a 4×4 ordered dither |
| Distance | Far tiles to the horizon | A fog wall at about a quarter mile on Phone, further on the other tiers |
| Cars | ~50k triangles each | ~12k (body stations 9× coarser, no underside, plain wheels) |
| Ground pictures | 7 MB of 1024 px photos | 66 KB: the same photos at 64 px and 32 colours, laid twice as large |
| File | 9.2 MB | 2.3 MB (most of it the police voices) |

Settings › Picture: rows, 15-bit colour, wobble (vertices snapped to the pixel grid, the PlayStation's
shimmer), flat shading (one shade per polygon on the land, buildings and trees), texture warp (affine
mapping). Settings › Display: Pixels, CRT, or the LED dots every Shiftlight game has had. The address bar
takes the same as overrides: `?lines=180&snap=0&warp=1&carlod=12`.

## Build

```sh
tools/build.sh                 # dist/redline-retro.html, one self-contained page
```

`tools/modules.txt` is the order the modules go in, all inside one script scope (the same as the full
game's single file). `tools/split.py` is the one-off that cut the full game into these modules.

## Where things are

| Path | What's in it |
| --- | --- |
| `src/11_retro.js` | **New.** The retro renderer: Shiftlight 3's GL helpers and frame pacing kept, its pipeline replaced. Same contract the game draws through (hooks `opaque`/`glass`/`particles`, `R.U`, `R.lights`), plus the rain. `RETRO` holds the picture settings |
| `src/13_lit.js` | The scene shaders, the full game's materials with the lighting swapped for the retro one (see `/* Redline Retro` comments) |
| `src/49_textures.js` | Generated by `tools/pack_retro_textures.py` from the full game's pack |
| `src/40`–`46` | Physics, ground contact, chassis, Sim, the robot drivers, the electric drive |
| `src/50_worldgen.js`, `51_world.js` | The county's generator and its streaming |
| `src/63_traffic.js` | Traffic on Highway 40: lanes, the intelligent driver model, lane changes, cars brought onto the physics near you |
| `src/64_streets.js` | Traffic on the town's streets and the county roads: loops, junctions, signals |
| `src/65_police.js` | Police mode: wanted levels, pursuit, your trail, the radio and loudspeaker voices, the helicopter |
| `src/68_people.js` | The county's people (Marisol, Deke, Rosa and the rest) and the jobs they give: the story's start |
| `src/67_challenges.js`, `66_clocks.js`, `62_race.js`, `61_career.js` | Challenges, lap clocks, races, the career |
| `src/70`–`76` | HUD, menu, garage, showroom, dyno lab, tune sheet, touch controls |
| `tools/shot.cjs`, `tools/tour.sh` | Headless Chromium checks: boot, drive in game time, screenshots round the county |

Every change from the full game outside `11_retro.js` and `49_textures.js` is marked with a
`Redline Retro` comment, so a change made to the full game can be carried across by hand.

## Testing

```sh
node tools/shot.cjs '[["wait",1000],["click","#mGo"],["drive",3,{"thr":1}],["shot","go"]]'
tools/tour.sh "downtown hwyE ridge" "day night"
```

Shots land in `/tmp/shots`. `drive` holds the game loop and steps it in game time with a set input, so a
slow machine still drives the same distance. The engine's synth is held silent unless `AUDIO=1`.
