# Reference image prompts

Ten prompts for reference images of the 4x4, coupe and wagon. Generate them landscape (16:9 or 3:2).
If your generator takes a reference image, give it the first image of each car (1, 4, 7) when you
make that car's other two, so all three show the same design.

The cars are original designs: no real make's grille, badge or name. Every prompt says so,
because generators like to copy a famous car.
