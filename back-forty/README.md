# Back Forty

All of the best pieces in one phone-first game: Dirt Sleeper HD's cars, garage and physics in a generated world 40 by 40 miles, with the model bay as a garage window (rev it, drive it on the dyno, pull a power sheet), a Plus tune for every build, the machines (quads, side-by-side, golf cart, go-kart, tractor, semi), and the Sleeper and Rock & Mud SUVs as the fastest things in it.

Open `back-forty.html` in a browser to play (made for a Pixel 7a held upright; also a laptop).

## What this file is

The published page, saved byte for byte (claude.ai artifact version `1793388981-4dc1`, sha256 `c64f72e2…ca380`). The source modules it was built from (on a local branch `back-forty/round-1`) were never pushed, so this page is the only copy. The page is the modules joined end to end with their comments, so it can be split back into them later.

- Built on Dirt Sleeper HD (which contains Mini Dirt Run Solo), with Mini Dirt Run Open World's generator in place of the ranch.
- HD's races and robot drivers are still in the code, switched off (their courses were the old ranch's).
- Saves use `b40-` keys only.
